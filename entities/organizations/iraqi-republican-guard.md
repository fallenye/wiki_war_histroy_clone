# 共和国卫队（al-Haras al-Jumhuri）

> 主源：[[sources/malovany-wars-of-modern-babylon|Malovany]] ch54（部队沿革，最完整的一节）、ch21—ch23（1988 年用法）。
> 并列：[[sources/arabs-at-war-pollack|Pollack]] ch2 对 1990—91 年共和国卫队的评价。
> 数字为伊方口径。

## 一、起源与双重身份

- 前身为 1963 年复兴党革命后设立的**国民卫队**（守护巴格达要点）。1968-07 政变中，其装甲与机械化
  两个旅（当时为**共和国卫队旅**与**第 10 装甲旅**）协助复兴党上台，此后成为政权最忠诚的部队（ch54）。
- 至两伊战争前编制为两个旅：
  - **共和国卫队旅**（机械化，无番号，编成 5 个营/团：2 机械化营、2 坦克团、1 个特种部队营即"第 3 营"）；
  - **第 10 装甲旅**——全军第一个（当时唯一）装备 T-72 的装甲旅。
- 定位（本书原词）："艰难任务部队"（difficult mission men）；兵员多为**提克里特**与忠于政权的部族、
  复兴党党员。

## 二、沿革时间轴（ch54）

| 时间 | 变化 |
|---|---|
| 1980-09 | 战争爆发后作为**总司令的战略预备队**投入，第 3 特种营参加霍拉姆沙赫尔攻城（1980-10）；10 装甲旅与机械化旅在头两年参加大量战斗 |
| 1982 下半年 | 新建**第 2 装甲旅**（由拟编 40 装甲旅改建，志愿兵、T-72） |
| 1984-04-28 | 扩编为**装甲师**（"Al-Fares"）；辖第 2、10 装甲旅与第 1 机械化旅，同期组建第 3 特种部队旅、第 4 步兵旅；设独立战斗学校 |
| 1985-03 | 第二次沼泽战役（新两旅首战） |
| 1986-04 后 | 法奥战后大扩编：当年底设 3 个师部（"Baghdad"步兵、"Al-Madina"与"Hammurabi"装甲） |
| 1988-04 前 | 再加三师（"Nebuchadnezzar""Al-Faw"步兵、特种部队师部）；此时共 **22 个旅**（4 装甲、2 机械化、约 11 步兵、3 突击、2 特种，另炮兵/工兵/架桥团等） |
| 1987→1988 | 由师级升为**军级**（军长 Hussein Rashid Muhammad）；1988-01 "Al-Madina"与"Hammurabi"在 Karbala-5、Karbala-8 以军级规模反击 |
| 1988-04—07 | 作为**进攻矛头**参加斋月行动与 Tawakalna 系列 |
| 1988 末—1989 | 新增 "Tawakalna 'ala Allah"（机械化）与 "'Adnan"（步兵，三突击旅）两师 → 8 个师 |
| 1990-08 | **单独执行入侵科威特**；为对联军作战再建 4 个师（"Al-Nida"装甲、"Al-'Abed"机械化、"Mustafa""Al-Quds"步兵）→ **12 个师**（参战者为 8 个老师） |
| 1991-03 | 镇压南方什叶派与北方库尔德起义的主力（见 [[events/iraq-1991-intifada]]（1991 年起事） |
| 1991 后 | 解散 5 个师（Al-Faw、Mustafa、Al-Quds、Tawakalna、特种部队师部），保留两个特种旅 |
| 1995 初 | 升格为**独立"军"**：首长改称"总参谋长"、授四星，与陆军总参谋长平级；增设"共和国卫队秘书长" |
| 1995 | 设两个军级司令部：**"Allah Akbar"**（巴格达以北，驻提克里特）与 **"Al-Fath al-Mubin"**（巴格达以南，驻 Suwaira） |
| 1996-08 | "Allah Akbar"军（"Baghdad""'Adnan"师）参与攻占埃尔比勒 |
| 2003-03 | 保卫巴格达与逊尼三角；"Allah Akbar"军辖 Hammurabi、'Adnan、Nebuchadnezzar；"Al-Fath al-Mubin"军辖 Al-Madina、Baghdad、Al-Nida；另由训练学院临时编成 1 个师（Kut 方向） |

## 三、训练与选拔（ch54）

- 1984 年设战斗学校 → 1987 年（军级）继续运作 → **1989 年建"模范训练学院"**（Institute for Exemplary
  Training），为卫队中央训练机构，设步、装、特种、炮兵等兵种学校。
- 每个师另设战斗学校；军官与士兵的忠诚审查严格，兵员优先取自提克里特及周边部族。
- 晋升通道：卫队军官大量占据军队关键职位（1989 年起 4 个军长出自卫队）。

## 四、作为"政权保卫部队"的一环（ch54）

萨达姆的五道安全圈：
1. 本人与家属的私人卫队；
2. **特别安全机构（SSO）**；
3. **特别共和国卫队**（见 [[entities/organizations/iraqi-special-republican-guard|其页]]）；
4. **共和国卫队**；
5. 军情、安全总局、情报总局与军队本身。

## 五、1988 年的用法（ch18、ch21—ch23）

- 1987 年 Karbala-5 首次以**军级规模在别军地段**执行进攻任务，由国防部长主持的前进总参协调；
  此法即 1988 年"胜利作战"的模板（ch18）。
- 1988 年斋月行动中，卫队军负责法奥半岛东侧沿阿拉伯河一线；Tawakalna-2 中与第 3、4 军协同渡水障。
- 本书评断：卫队"是 1988 年胜利的矛头"，其成长是"萨达姆时代的核心军事现象之一"（ch54 总结）。

## 六、与 Pollack 的对照

Pollack（其页）的核心观察：**同一个共和国卫队，在演练过的按部就班作战（入侵科威特）中表现良好，
二十六天后一旦被迫进入流动战（1991-02）就几乎崩溃**——这是他"剧本内/剧本外"框架最干净的实证。
Malovany 对 1991 年的记述与此不冲突（见
[[events/iraq-1991-desert-storm-ground-war|地面战]]），但他更强调卫队在 1988 年的成功与
1991 年"编制与士气尚存"的一面（ch54）。
