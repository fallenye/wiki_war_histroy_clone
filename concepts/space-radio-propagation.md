# 空间无线电传播（Radio Propagation in Space）

技术参考层页面。Adamy《EW 105》Ch5 汇总的**星-地链路特有的传播损耗**：视距（LOS）损耗、
大气损耗（随仰角）、天线失配（misalignment）、极化损耗（含法拉第旋转）、雨衰（0°C 等温线）。
作为技术参考，不作为具体历史事件的史料。地面大气传播（视线/双径/菲涅尔区/刀边）见
[[ew-link-equation-and-db-math|链路方程]] 与 [[ew-against-communications|对通信的 EW]]。

接收功率：`P_R = ERP − L + G_R`（ERP 发射有效辐射功率、L 收发间损耗、G_R 接收天线增益）。
**星-地总路径损耗** = LOS 损耗 + 大气损耗 + 天线失配损耗 + 极化损耗 + 雨损耗。

## 1. 视距（LOS / 空间）损耗

星-地链路损耗主项来自极远距离，即**空间损耗/LOS 损耗**：

`L = 32.44 + 20 log(d_km) + 20 log(F_MHz)`

- 这是**两个各向同性天线之间**的损耗；收发天线增益/损耗**另行计入**。
- **大型卫星**链路天线通常是大增益、窄波束的**抛物面盘**：
  - 增益 `G = −42.2 + 20 log(D) + 20 log(F)`（D 反射面直径 m、F MHz、效率 55%）。
  - 3-dB 波束宽度 `BW = antilog[(86.8 − 20 log(D) − 20 log(F))/20]`（度）。
- **小型卫星**天线可为螺旋或偶极子。
- 算例：卫星到地面站 1,000 km、15 GHz → 空间损耗 **175.96 dB**。

## 2. 大气损耗（随仰角）

- 星-地链路用“**穿整个大气层**”的损耗图（对照地面链路的“每 km 损耗”）。
- 它是**频率与卫星相对本地地平线仰角**的函数：仰角越低（越贴地平线）损耗越大。
  例：3 GHz 信号在 30° 仰角可忽略，在地平线（0°）约 **2.2 dB**。

## 3. 天线失配（Antenna Misalignment）

窄波束天线链路中，发/收天线指向偏差会因有效增益下降造成链路损耗。**小偏差**下：

`ΔG = 12·(θ/α)²`（ΔG 相对视轴增益的下降 dB、α 为 3-dB 波束宽度°、θ 为偏角°）

例：发射天线 3-dB 波束宽度 5°、偏 1°、接收天线正对 → 接收信号降 `ΔG = 12(1/5)² = 0.48 dB`。
**发、收天线的失配都要计入总链路损耗。**

## 4. 极化损耗（Polarization Loss）

- 来波极化与接收天线极化**相同**则无极化损耗；不同则有损耗。
- 星-地链路的复杂性：信号**穿过大气层**会改变极化（**法拉第旋转**等）。
- 卫星上/下行可用**同一天线同时工作**（若两链路为**反向圆极化**）。
- 小型地面/机载天线有时为**线极化**，而航天器天线为**圆极化**——链路一端线极化、另一端右旋或
  左旋圆极化时，有 **3 dB** 极化损耗。
- 汇总：**匹配圆极化**损耗为 0；**反向圆极化**损耗大；**圆极化-线极化**为 3 dB。

## 5. 雨衰（Rain Loss）

- 雨衰每 km 损耗由**频率与降雨率**查图，再乘以链路穿过雨的**距离**。
- **空间链路额外复杂性**：太空无雨，故雨衰**只适用自降雨起始高度到地面站**之间——降雨始于
  大气温度为 **0°C 的等温线（0°C isotherm）**高度；此高度以上雨已冻结、冰的衰减可忽略。
- 穿过雨的路径长 = **0°C 等温线高度 / sin(卫星仰角)**（见图）。若卫星-飞机链路，地面端取飞机高度。
- 因雨衰常按**概率**而非逐时刻计算，用“**0°C 等温线高度 vs 纬度**的概率图”很实用：如要 99% 可靠度，
  自地面站纬度上到 1% 线再左读等温线高度。算例：40° 纬度、1% 线约 2 km 高、卫星仰角 30° →
  穿雨 4 km；15 GHz 大雨 0.73 dB/km → **2.9 dB**；小雨 0.033 dB/km → 0.3 dB。
- 卫星仰角可由地面站-卫星-地心**平面三角形**求得。

## 6. 作战意义与研究价值

- 星-地链路五大损耗项是空间链路预算的通用组件，连接 [[satellite-communication-links|卫星链路]]
  （EW 102 的噪声温度体系）与 [[satellite-link-vulnerability|链路脆弱性]]。
- **天线失配 `12(θ/α)²`** 对空间干扰极关键：干扰机天线指向偏差会直接削弱有效 ERP（见
  [[jamming-from-space|空间干扰]] 算例）。
- 大气/雨衰**随仰角**的特性解释了低仰角星-地链路的困难；0°C 等温线概率图是雨衰工程估算的实用工具。
- 极化（法拉第旋转、圆 vs 线 3 dB）是星-地链路设计的重要考量。
