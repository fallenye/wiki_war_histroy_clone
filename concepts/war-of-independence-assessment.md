# 1948 年战争的评价：本书的总结

> 单源未校：据 [[sources/arab-israeli-wars-herzog|Herzog]] Book I, Summary（PDF 页 104—108）。
> 这是本书七卷共用的结论框架的最初一环，其"以色列靠 Ben-Gurion 的领导与牺牲精神取胜、阿拉伯败于
> 内斗与基层指挥"的判断，在此后各卷反复出现（对照 [[concepts/lebanon-war-1982-assessment]]）。

## 对 Ben-Gurion 的评价（本书最高）

- 本书把他与**丘吉尔、罗斯福、戴高乐**并列：有远见、能看透数步之后、能抓住国家面临的根本问题，
  有在"最不可能的劣势"下领导、并向人民索取最大牺牲的勇气；
  有把不同观点与哲学的人焊接到一个共同目标上的人格与领导力（ch4 Summary）。
- 具体判断："早在 **1945 年底**，他就看清与英国达成协议没有可能，
  因此在巴勒斯坦的犹太人必须为一个民族军队与一场全面战争做准备"；
  "若他没有抓住这一新发展的意义，事件将把他们抛在后面、政治上军事上都毫无准备"（ch4 Summary）。
- 本书的对比：当同事与政敌"还在以奇袭与小部队作战为念"时，Ben-Gurion 已认定"没有折中、只能走到底"；
  他**在一切阶段坚持为全面战争做准备**，对"建国的含义"有清晰理解——
  "这有时与某些过时的犹太复国主义意识形态的混乱与矛盾相冲突"（ch4 Summary）。
- 结语式的一句话："他犯过错误，但他的过失是**一个非常伟大的人**的过失。若没有他的远见、想象力与决心，
  很难说灾难是否能被避免。"（ch4 Summary）

## 对以军将领与部队的评价

- "回过头看，除 **Yigal Allon、Shimon Avidan** 等少数杰出的例外，以色列的将领们缺乏经验、缺乏想象力"，
  这一缺陷"在相当程度上被 Ben-Gurion 压倒性的人格、能力、远见与对问题的理解所弥补，
  也被以色列战场指挥员非凡的勇气所弥补"（ch4 Summary）。
- 战斗的重担落在**营、连一级**；此后以色列军官与军士的战斗作风（领导规范、身先士卒、自我牺牲）
  "是在独立战争中确立的"；后来指挥 IDF 打了四场战争的许多将领，都出自独立战争中的营连排长（ch4 Summary）。
- 军队性质："一支实际上以 Haganah 为主、加上 Irgun 与 Lehi 成分的**游击军**，
  在战火中长成了正规军"；其"以平民为主体"的性质"为未来定下了模式"——
  IDF 始终是一支由较小常备部分与庞大预备役构成的公民军队（ch4 Summary）。
- 预备役体制："由第二任总参谋长 **Yigael Yadin** 在建国后建立"，并被本书称为以军
  "此后相对'随和'的气氛"的来源（ch4 Summary）。

## 由劣势生出的军事哲学

- 人力薄弱、缺现代武器、须同时在多条战线作战——这三点"演化出一种以**灵活性、奇袭与创新**为基础的军事哲学"（ch4 Summary）。
- **夜战**"几乎成了以军的第二天性"，因为黑暗在一定程度上抵消了阿拉伯军队的优势；
  "独立战争中的以色列进攻几乎全部在夜间发起"（ch4 Summary）。
- 速度、突击队式作战、迂回机动——"三者共同塑造了新兴以色列军队的性格与作战方式"；
  与之相伴的是"鼓励战场指挥员随时适应战局变化、利用变化中的形势"的思想灵活性，
  "僵化的做法与过度依赖上级命令，在以色列军队中没有位置"（ch4 Summary）。

## 对阿拉伯一方的评价

- "除 Kaukji 的阿拉伯解放军外，所有阿拉伯军队在**防御**中都表现得非常有效"——
  这一点"在此后多年一直是它们的特征"（ch4 Summary）。
- 但"**进攻**时的失败源于：当其按预案的进攻遇到意外障碍时，战地基层领导无力迅速适应变化"（ch4 Summary）。
- 更根本的是**阿拉伯国家间的内斗**："它们虽然都打以色列，却总在回头提防盟友，处在互不信任的气氛中"；
  因此"从未能真正利用其压倒性优势"；而以军"沿内线作战"，
  得以在各条战线间调动兵力、对某一支阿拉伯军队发展进攻，
  "因为它知道其他战线不会形成协同的军事压力"（ch4 Summary）。
- 前方页内已分别记录了本书对埃军（攻弱守强、死板照本）、军团（最有效）、ALA（组织涣散）的具体评价，
  见 [[events/war-of-independence-southern-front-1948]] 与 [[concepts/arab-legion-1948]]。

## 本书的自我保留

- 本书未对 1948 年的**阿拉伯难民责任**作任何反向讨论（只引阿拉伯方面的自认），
  也未讨论代尔亚辛事件的责任（只记"阿拉伯人多年反复以此为其暴行辩护"）；
  这些留白已在 [[concepts/arab-refugee-problem-1948]] 与 [[concepts/plan-d-1948]] 中明示。
- 本书的结语："独立战争中，以色列的命运曾悬于一线。它被 Ben-Gurion 伟大而历史性的领导所拯救，
  被他所领导的、有生存意志并准备为此作出一切牺牲的民族所拯救。
  那牺牲在独立战争中付出了，**但在往后的岁月里还要继续被索取**。"（ch4 Summary）


## 第二口径：Van Creveld 的伤亡统计与"代价论"（ch7）

> 据 [[sources/idf-van-creveld-sword-olive|Van Creveld]] ch7。这是**全库现有最细的一组 1948 年人员统计**，
> 与上节 Herzog 的"军人逾 4,000、占人口 1%"属不同粒度，**并列保留**。

| 项目 | 数字 |
|---|---|
| 全期死亡（本书口径） | **5,682** |
| 其中军人 | **4,520**（79.5%） |
| 其中平民 | **1,162**（21.5%） |
| 男性死亡 5,213 中平民 | 801（15%） |
| 女性死亡 469 中平民 | 361（76.9%） |
| 女性在军中的死亡 | **108**（占军人死亡 2.4%）；1948-12 女性占兵力 10.6% |
| 阶段分布 | 1947-11—1948-05 约 **2,000**；1948-05-15—06-10 **1,200**；1948-07—1949-01 其余 |
| 年龄结构 | 18—30 岁占死者 **64.8%**（占总人口 47.1%）；17—20 岁死亡 6%，21—25 岁逾 5% |
| Latrun 诸次攻击 | 阵亡 **383** 人（其中 3 名女性：1 名无线电报务员、2 名护士） |

- 作者的换算：这场战争占"1947 年底以来以色列全部战争死亡"的约**三分之一**；
  按人口与时程折算，"比英德在 1914—1918 年经历的更密集，比法国在同期的入口灾难也差得不远"（ch7）。
- 作者对"失去的一代"说法的处理：教育与领导层（军官与士官）在死者中占比偏高，
  但"超额损失"不足以支持"一代人质量受损"的流行说法；他认为这组数字反而说明**部队的战斗意志与牺牲意愿**（ch7）。
- 女性：作者强调"相对人口份额，女性死亡远少于男性"，且在平民中超额、在军人中不足额；
  同时列举"手持武器战死、在岗位上死亡、在保卫定居点中死亡、以及承担战时不亚于战斗的日常劳动"的女性（ch7）。
- 纪念：至 1953 年至少出版 **320** 种纪念书籍；作者另引诗人 Uri Tsvi Greenberg 追悼一名前 LECHI 成员的挽诗（ch7）。

### 与本书其他部分相连的判断

- "1948 年是唯一一场以色列可能接近战败、甚至接近肉体灭绝的战争"（ch7）——与他在 ch14 的对照（1973 年战争"最昂贵"）互为两条标尺。
- 伤亡之重与"缺乏训练、缺乏经验"直接相联，而非怯战；作者引 Sharon"我们不知道的东西太多"与 Ben Gurion
  "我们的军人都是好锡安主义者，但还没成为军人"（ch7）。
