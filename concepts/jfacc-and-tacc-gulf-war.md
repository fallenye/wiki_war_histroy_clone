# JFACC 与 TACS/TACC

> 依据：[[sources/putney-airpower-advantage|Putney（来源㉛）]] ch1、ch5、Epilogue。本页是"1991 年空中战役
> 为什么能统一指挥"的制度解答，也是全书对**军种间拉扯**最集中的一节。

## 一、定义与权力来源

- **JFACC（Joint Force Air Component Commander，联合部队空中成分司令）**：由联合部队司令（JFC）
  **任命**（可以选择，但没有义务），负责"空中资产集中、统一控制"。1991 年 Horner 是
  **美国第一次在重大地区冲突中担任 JFACC 的人**。
- **权力来源**：1986 年《戈德华特—尼科尔斯国防部改组法》。该法把指挥链明确为
  总统 → 国防部长 → 联合作战司令部司令；联参会主席可以凭职务直接向总统提建议，
  **不需要参联会一致意见**；各军种参谋长与 TAC 司令被**排除在作战指挥链之外**。
- **三个兼职**：Schwarzkopf 任命 Horner 同时担任 **JFACC ＋ ACA（空域控制权）＋ AADC（区域防空司令）**。
  ACA 负责 AOR 内空域的统一管理；AADC 整合各成分与盟军的全部防空武器系统。

## 二、TACS 的十个组成部分（书中清单）

| 部件 | 功能 |
|---|---|
| **TACC**（战术空军控制中心） | 整个系统的"神经中枢" |
| CRC（控制与报告中心） | 机动或固定雷达站 |
| CRP（控制与报告哨） | CRC 下属的雷达监视控制站 |
| 前方空军控制哨（FACP） | 高机动雷达分队，填补雷达覆盖空隙 |
| 消息处理中心 | TACS 各部分之间的自动化通信 |
| **AWACS** | 空中雷达预警与控制平台 |
| 空中战场指挥控制中心 | 无雷达的空中指挥平台，用于超出地面通信距离时 |
| **ASOC**（空中支援作战中心） | 通常配属军指挥所 |
| TACP（战术空军控制组） | 配属军、师、旅、营，隶属 ASOC |
| 联队作战中心 | 联队级的架次管理与控制 |

## 三、"分摊（apportionment）"与"分配（allocation）"——一个说不清的问题

1989 年参联会的定义：
- **apportionment**：确定并分配"某一时期内应投入各类空中行动和／或地理区域的总体努力的百分比和／或优先级"；
- **allocation**：把分摊"翻译成各型飞机的架次数"。

**书中最能说明问题的一段对话**（1989-02-21，Horner 在肖空军基地首次见 Schwarzkopf）：
Schwarzkopf 说他作为 CINCCENT **分摊**空中力量，JFACC 则**分配**它；
接着**承认自己其实不知道怎么分摊**。Horner 回答：**"我也不知道，没人知道。"**
作者注：这两个"坦白"令人吃惊，因为陆军与空军自 1981 年起就在正式讨论这些概念，
1984 年两军参谋长还签过联合协议，空军条令手册里也写过。

**Horner 提出的替代办法**（被 Schwarzkopf 接受并影响整个战争）：
「你只要告诉我你想达成什么，我来选目标。」他按载荷、航程、能力分配飞机；
**"归根到底是目标选择（targeting），不是努力程度（level of effort）"**。

## 四、Horner 的"三不谈"与作战遗产

**（1）不谈"战略／战术"**。书中反复出现他的口头禅：「Air is air. It's not strategic air, it's not
tactical air. It's air!」他禁止部下用这两个词描述飞机与目标；1990-08-20 对 Deptula 直接说
「别用战略和战术这两个词。目标是目标（Targets are targets）」。

**（2）不搞"route package"**。看到 Instant Thunder 把空域按地理扇区分给空军、陆战队、海军时，
他严厉指示：「**不要按 route package 去 deconflict。我们在越南干过，绝不再干。**」
书中的判断：他"宁可辞职也不会把空域按海军／空军的地理或军种扇区划分"。

**（3）不浪费架次**。他反对"alert CAS"（飞机停在警戒线上等呼唤），
理由是"任何一架没在装弹、飞向目标、飞离目标或再次出动的飞机，都是浪费的资产"；
并引他的原话：「陆军明白这个道理——他们说炮兵从不留预备队。**空中力量也不留预备队。**」
由此发展出 **Push CAS**：按前一天的规划把架次持续"用水管"送到战场，需要时由 TACC 在飞行中改派任务。

## 五、JFACC 权威在战争中的两次危机

**（1）1991 年 2 月，地面战前的"分蛋糕"会议**。Horner 解释 Push CAS 后，第七军军长
**Franks 无视他的说明，要求每天给第七军数百个 CAS 架次**（不论是否需要）。Horner 当场愤怒反驳。
他的回忆是："所有人都看着我，说'他把自己捅了一刀，真可爱'。"
接着陆战队的 Boomer 也来要，第 18 空降军的 Luck 也加入。
**Schwarzkopf 出面终止辩论**：「你们这些人不明白。**这都是我的空中力量，我爱怎么用就怎么用。**」
Horner 的评语："争论就此结束，我们保住了集中指挥。"

**（2）G 日前的怒火**。Epilogue 记：Schwarzkopf 在开战前两天对空军"大发雷霆"，
认为空中计划有严重缺陷，最后由 JFACC 安抚并说服他"维持原案"。

## 六、书中最锋利的一段自白（Horner 论越南教训）

> 「这就是越南的教训。记得我们伟大的总统说：'**只要我不批准，他们就不能在北越炸一个茅房。**'
> 而我，就是那个在炸茅房的人，我绝不会让这种事在我在位时重演，因为那是不对的。
> 如果想知道一场战争会不会赢，**只要问目标是在哪里选的**。如果他们说'我们是在华盛顿选的'，
> 那就离开这个国家吧。去加拿大，直到战争结束，因为这场战争输定了。」

## 七、本库的处理

- 本页的叙述**全部出自 Putney 的官方史**，其中引语为规划人员访谈原话（书中注明）。
- 与 [[sources/hallion-storm-over-iraq|Hallion]] 的重叠处：两人都强调 Horner 的集中控制与反 route package；
  但 Hallion 把 JFACC 的胜利写成制度自然演进，Putney 则记录了每一次具体的争夺与妥协。
- 与 [[sources/karlin-inheritance|Karlin]] 的对照：Karlin 论证 911 后文官监督**萎缩**；
  Putney 这里展示的是 1991 年 JFACC 制度**刚刚建立、权威尚未稳固**的状态——两者是同一制度的不同阶段。
