# EW 天线参数与选型（EW Antennas）

技术参考层页面。Adamy《EW 101》Ch3 汇总的**天线参数定义、增益-波束-面积关系、极化与类型选型**
是可跨战争、跨装备复用的技术框架。本页汇总参数定义、关键关系式与选型指南，不作为具体历史事件
的史料。

## 1. 天线在 EW 中的作用

接收系统中提供增益与方向性；测向系统中天线参数是确定到达方向的数据来源；干扰系统中提供增益与
方向性；威胁辐射源（尤其雷达）的**天线增益方向图与扫描特性**是识别威胁信号的重要途径之一，
其**扫描与极化**还支持某些欺骗对抗手法。

## 2. 天线性能参数定义（Table 3.1）

- **增益（Gain）**：信号经天线处理后的强度增量（dB），可正可负；全向天线增益为 1（即 0 dB）。
- **频率覆盖（Frequency coverage）**：天线能正常收发并提供相应参数性能的频率范围。
- **带宽（Bandwidth）**：以频率计的频率范围，常以后分比带宽表示
  `100% × (f_max − f_min)/平均频率`。
- **极化（Polarization）**：收发 E/H 波的取向，主要为垂直、水平、右旋/左旋圆极化；亦可斜线
  （任意角）或椭圆。
- **波束宽度（Beamwidth）**：天线的角度覆盖，通常以度计。
- **效率（Efficiency）**：实际收发功率与“天线波束所覆盖球面比例对应的理论功率”之比。

## 3. 天线波束相关定义（易被误述之处）

- **Boresight（视轴）**：天线设计指向，通常为最大增益方向，其他角度参数相对它定义。
- **主瓣（Main lobe）**：主/最大增益波束，以“增益 vs 离轴角”定义。
- **波束宽度（Beamwidth）**：通常指 **3-dB 波束宽度**——增益降到视轴增益一半（−3 dB）处的
  **双边角**。如 3-dB 波束宽度 10°，则离轴 5° 处即 −3 dB，两个 3-dB 点相距 10°。
  亦可定义 **“ny” dB 波束宽度**（任意增益下降电平，如 10-dB 波束宽度）。
- **旁瓣（Side lobes）**与**后瓣（Back lobe）**。
- **到第一旁瓣的角（Angle to first side lobe）**：视轴到第一旁瓣最大增益方向的角，为**单边值**
  （注意：它可能小于主瓣波束宽度——因波束宽度是双边、旁瓣角是单边）。
- **到第一零点角（Angle to first null）**：视轴到主瓣与第一旁瓣之间最低增益点的角，亦为单边值。
- **旁瓣增益（Side-lobe gain）**：相对主瓣视轴增益给出（大的负 dB）。**天线不按特定旁瓣电平
  设计**——旁瓣被视为“坏东西”，厂家只认证其低于某电平。但 EW/侦察视角下必须知道**欲截获发射
  天线**的旁瓣电平；EW 接收系统常设计为接收 **“0-dB 旁瓣”**——即旁瓣相对主瓣增益下降“该增益”
  的数值（例：40-dB 增益天线的“0 dB 旁瓣”会比视轴对准时低 40 dB 发射）。

## 4. 极化要点

- 极化不匹配会降低接收功率。**线极化天线几何通常与其极化取向一致**（垂极天线趋垂直）；
  **圆极化天线**趋圆或交叉，分右旋（RHC）/左旋（LHC）。
- 损耗范围 **0 dB ~ 约 25 dB**；**任何线极化与圆极化组合间为 3 dB 损耗**。
- **重要技巧**：用**圆极化天线**接收**极化未知的线极化信号**，**总损失 3 dB**，但避免交叉极化时
  可达 **25 dB** 的损失。信号极化完全未知时，常用 LHC 与 RHC 天线快测并取较强者。
- 25 dB 交叉极化是 EW 宽带天线的典型值；窄带（如通信卫星链路）可做到 >30 dB 隔离；RWR 中的
  小型圆极化天线交叉极化隔离可低至 **10 dB**。

## 5. 天线类型选型（Table 3.2）

按**角度覆盖（360° 方位 vs 定向）× 极化（线/圆）× 带宽（窄/宽）**三维选型：

- **360° 方位 + 线极化**：窄带→鞭状/偶极子/环天线；宽带→双锥或卐字（swastika）天线。
- **360° 方位 + 圆极化**：窄带→法向模螺旋；宽带→Lindenblad 或四臂圆锥螺旋。
- **定向 + 线极化**：窄带→Yagi、偶极子阵、带喇叭馈源的抛物面；宽带→对数周期、喇叭、
  带对数周期馈源的抛物面。
- **定向 + 圆极化**：窄带→轴向模螺旋、带极化器的喇叭、带交叉偶极子馈源的抛物面；
  宽带→腔背螺旋、圆锥螺旋、带螺旋馈源的抛物面。

各类天线的典型规格（极化/波束宽度/增益/带宽/频率范围）见该书图 3.3。选天线须满足所需**角度覆盖、
极化、频率带宽**三要素；“典型”频率范围源于物理尺寸/安装/应用的实际约束。

## 6. 抛物面天线参数权衡（必用关系式）

抛物面是最灵活的天线之一：馈源置于焦点，把抛物面上的能量汇聚为同向（理想馈源辐射全部能量到
盘面，实用约 **90%** 即视为理想）。理想抛物面天线方向图含主瓣、后瓣与旁瓣。关键关系：

- **增益 vs 波束宽度**：对一定类型天线，增益与波束宽度存在确定权衡（该书给出 55% 效率抛物面
  的增益-波束宽度图；EW/侦察常用的宽带（一个八度以上）天线效率低于 55%）。
- **有效天线面积**：`A = 38.6 + G − 20 log(F)`，A 为 dBsm（相对 1 m²）、G 为视轴增益(dB)、
  F 为频率(MHz)。（该图线以 1 m² 有效面积、0-dB 增益发生在约 85 MHz 为基准。）
- **抛物面增益 vs 直径与频率（55% 效率）**：`G = −42.2 + 20 log(D) + 20 log(F)`
  （D 为直径 m、F 为 MHz）。示例：0.5 m 直径、10 GHz 时增益约 32 dB。此式假设盘面为抛物线、
  精度到工作波长的很小一部分，否则增益下降。

- **工作原理**、**阵元间距（element spacing）**、**波束宽度**、**增益**、

## 8. 通信天线类型（据 EW 103 增量）

[[sources/ew-103-adamy|EW 103]] 对**通信天线**的补充（天线不管调制，故与通用天线同源）：

- **鞭状天线（whip）**：战术通信最广用；**其有效高度取天线底部（安装面）的高度**——是传播方程
  的重要输入（机载单极天线亦然）。
- **对数周期天线（log periodic）**：通信的优良选择，可设计成有相当增益（定向、宽带），用于固定
  站间通信以增增益与隔离。
- **抛物面盘天线**：广用于数据链与卫星通信。
- **偶极子天线**：广用于战术 DF 阵列；**阵列偶极子须配匹配网络（matching network），其增益被
  显著降低**（频段低端可低至 −20 dB）——方向性/带宽与增益的权衡。

## 9. 作战意义与研究价值

- 天线增益-波束-面积关系式是[[ew-link-equation-and-db-math|链路预算]]的组件，跨装备可比。
- 极化技巧（圆极化稳收线极化信号）与旁瓣电平（“0-dB 旁瓣”）是侦察/干扰设计的通用考量。
- 天线**扫描与极化为威胁识别与欺骗对抗提供途径**，连接 [[ew-processing-and-threat-id|威胁识别]]
  与 [[jamming|欺骗干扰]]。
- 通信天线的有效高度/匹配网络增益损失，是通信链路预算与截获/干扰距离计算的实际输入。
