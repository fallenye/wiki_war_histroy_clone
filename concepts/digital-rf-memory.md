# 数字射频存储（Digital RF Memory, DRFM）

技术参考层页面。Adamy《EW 104》Ch8 汇总的 **DRFM 原理、宽带/窄带体制、相干干扰、对脉冲压缩/频率
捷变/前沿跟踪等技术的对抗、复杂假目标、时延问题**。DRFM 是支撑新一代电子对抗的关键技术——它允许
快速分析复杂接收波形并生成对抗波形，可把干扰系统对复杂波形的效能提高许多 dB。作为技术参考，
不作为具体历史事件的史料。

## 1. DRFM 框图与基本原理

- **流程**：下变频到合适中频（IF）→ 数字化 IF 带宽 → 存入存储器交计算机分析/修改 → 修改后的
  数字信号变回模拟 RF → **用同一本振**变回接收频率（单一本振保持下/上变频的**相位相干**）。
- **关键元件是 ADC**：须支持约 **2.5 样本/赫兹**的数字化率（**高于**数字接收机所需的 Nyquist
  2 样本/赫兹——因信号要被**重构**），且输出 **I&Q**（同相/正交，相距 90°）以捕获相位；通常每样本
  数比特（也有 1-bit 或相位-only 数字化的场合）。
- 计算机分析捕获信号（含调制特性与参数），一般**分析收到的第一个脉冲**并生成后续脉冲（相同或
  系统变化的调制参数）。
- **DAC 位数多于 ADC**，以保证重构 RF 信号质量不降。

## 2. 宽带 DRFM

- 数字化**宽 IF 带宽**（可含多个信号）；干扰系统调谐覆盖须干扰的威胁频率段。
- **频率变换与回变用系统单一本振**以保持相位相干。带宽受 ADC 数字化率限制。
- 因带宽内**可能有多信号**，须很大**无杂散动态范围**→ ADC 取最大实用位数。
  **数字电路动态范围 = 20 log₁₀(2ⁿ)**（n 为位数）；**ADC 前的模拟电路须有同等动态范围**。
- 宽带 DRFM 很理想（可处理宽频调制与频率捷变威胁）。**趋势**：数字化器进步→更宽更多；数字化
  速度与位数成反比，未来 DRFM 驱动需求是"更多样本/秒 + 更多位/样本"。提高采样率/位数的两法：
  ①用不同电压电平的多个 1-bit 数字化器（无需计算机、极快，输出合并成高速多位字）；②在抽头延时线
  输出上放多个多位数字化器（时延错开采样，合并成高速多位输出）。

## 3. 窄带 DRFM

- 只需宽到能捕获干扰机须处理的最宽信号——ADC 在技术水平内即可。
- 干扰系统把感兴趣的频率范围变换为**多个窄带 DRFM**覆盖的范围；输入功率分配至各 DRFM，各调谐到
  单一信号执行功能，模拟 RF 输出合并后（相干地）变回原频率范围。
- **杂散响应在窄带 DRFM 中问题较小**（各只含一个信号）。

## 4. DRFM 功能：对脉冲压缩雷达的对抗

DRFM 对**脉冲压缩**雷达尤有价值（两类压缩：chirp、Barker 码）：

- **Chirp**（每脉冲加线性调频）——雷达用压缩滤波器把有效脉宽按 FM 扫频范围/相干带宽之比缩短；
  无此调频的干扰脉冲，**有效 J/S 按压缩比缩减**。DRFM 生成 chirp 干扰脉冲即**保持满 J/S**。
- **Barker 码**（每脉冲 BPSK 码调制）——雷达接收端抽头延时线位数=码位数，正对齐时各比特同相
  叠加、否则近零，把接收脉冲缩短到 1 个码位时长（压缩距离分辨=码位数比）；无 Barker 码的干扰
  脉冲不压缩，**有效 J/S 降码位数倍**。DRFM 生成带正确 Barker 码的干扰脉冲即**保持满 J/S**。

## 5. 相干干扰（对 PD 雷达）

- PD 雷达处理矩阵中，真目标相干回波落**单个**窄多普勒滤波器；**非相干**干扰（阻塞/点噪声）进入
  **多个**滤波器，雷达据此拒绝干扰、优先其相干信号。
- **有效 J/S 提升**：PD 雷达的**处理增益 = CPI × PRF**。算例：圆周扫描周期 5 s、波束 5°、PRF 10,000
  → 照射时间 = 5 s×(5°/360°) = **69.4 ms**（即 CPI），处理增益 = 0.0694×10,000 ≈ **964 ≈ 28.4 dB**
  ——即噪声干扰的有效 J/S 可被压低约 28 dB。
- DRFM 能产生**相干干扰**信号，故 PD 雷达对干扰信号给予同样处理增益、**无法检测干扰存在**——
  既提高 J/S，又**防止触发 HOJ**。
- 相关技术：**箔条**（PD 雷达可辨其频率展宽）、**RGPO/RGPI**（DRFM 产生相干假脉冲）、**雷达积分
  时间**、**CW 信号**等。

## 8. 复杂假目标（8.10）

- 现代雷达（尤其 **SAR 与 AESA**）可刻画**复杂目标**的 RCS——含许多散射点（各带相位、幅度、
  多普勒、极化）。多回波合成复杂皮肤回波供雷达分析以准确识别目标。
- **非相干干扰机的简单假目标**波形与真实皮肤回波显著不同→具最新处理能力的雷达可**拒绝 RCS 特征
  错误的假目标**。故**有效干扰现代雷达**要求 RGPO/RGPI 等产生的假目标具备**正确的复杂波形**。
- **RCS 数据生成**：计算 RCS 数据（DRFM 可用以生成逼真复杂假目标）。

## 9. DRFM 使能技术与配置

- **捕获复杂目标**、DRFM 配置；**干扰与雷达测试**（DRFM 亦用于雷达测试）。单个 DRFM 单元用 FPGA
  技术可仿真 **12 个散射点**（含控制与多普勒频移功能）。

## 10. DRFM 时延问题（8.13）

DRFM 与处理器**捕获并分析收到的第一个脉冲**、在回发后续脉冲时复制该脉冲特性（假定所有脉冲相同），
回发脉冲与接收脉冲相干，并施加支持干扰手法（如逐次延时/频移）。**处理时延须短于脉冲间期**：

- **相同脉冲**：时延须在脉冲间期内完成（几十微秒到几毫秒）。
- **相同 chirp 脉冲**：例：跟踪雷达脉宽 10 µs、占空比 10% → 脉冲间隔 = 脉宽/占空比 = **90 µs**，
  故 DRFM 处理吞吐时延（取数字化脉冲数据→定脉宽调制参数→生成干扰脉冲→返回数字信号）**须 < 90 µs**。
  处理须在脉冲间期测出频率调制**斜率**（可线性或非线性），按多个时间增量生成全脉冲数字表示，
  回发信号为调频的**阶梯近似**并按干扰手法做频移/时移。
- **相同 Barker 码脉冲**：DRFM 数字化首脉冲，处理器确定码时钟率、0/1 序列、接收频率、到达时间，
  生成 1-bit 与 0-bit 数字信号，再按后续各脉冲输出正确 BPSK 调制脉冲（含正确频率、多普勒与延时）。
- **唯一脉冲**：每脉冲不同时无法简单复制。

## 11. 需 DRFM 对抗的雷达技术小结（8.14）

传统干扰机难以对抗、须 DRFM 的雷达技术：

- **相干雷达**：非相干干扰（即便点噪声）跨多个滤波器→雷达可检测干扰并触发 HOJ，且 J/S 被相干脉冲
  处理增益压低；**DRFM 可产生相干干扰信号**，雷达对干扰也给处理增益、无法检测干扰→提高 J/S 且
  防 HOJ 激活。
- **前沿跟踪**：使 RGPO 失效（干扰脉冲逐次延迟于皮肤回波，雷达只跟踪前沿）；**现代 DRFM 时延极短
  （约 50 ns）**，可及时生成干扰脉冲捕获前沿跟踪器→使 RGPO 与**地形反射**干扰重新有效。
- **脉间频率跳变**：传统干扰机须覆盖整个跳频范围（J/S 大降）；**DRFM 测首 50 ns 频率**即可产生跟随
  跳频的干扰信号，覆盖极高比例的皮肤回波脉冲。
- **脉冲压缩**：干扰须带压缩调制（chirp/Barker），否则 J/S 降压缩比。
- **距离变化率/多普勒相关**、**目标 RCS 详细分析**、**高占空比脉冲雷达**：均须 DRFM 型对抗。

## 12. 作战意义与研究价值

- DRFM 是把干扰从"非相干噪声"升级到"**相干/波形匹配干扰**"的核心技术，解释了 1990 年代后
  抗新体制雷达（PD、脉冲压缩、频率捷变、前沿跟踪）的干扰为何普遍以 DRFM 为中心。
- 处理增益 = CPI×PRF、相干 vs 非相干在 PD 矩阵中的判别，是理解 DRFM 价值的定量基础。
- "时延须 < 脉冲间期""约 50 ns 捕获前沿/测频"等指标，界定了 DRFM 的工程约束。
- 复杂假目标与 RCS 特征匹配，连接 [[radar-decoys|诱饵]]（DRFM 使诱饵更逼真）。
