# 辐射源定位系统精度

技术参考层页面。Adamy《EW 102》Ch6 深入汇总的**定位精度度量（RMS/CEP/EEP）、误差预算、以及精确
定位技术（TDOA/FDOA）**。这是对 [[emitter-location|辐射源定位与测向页]]的重要深化（EW 102 新增
FDOA、CEP/EEP、误差预算合成等）。作为技术参考，不作为具体历史事件的史料。

定位精度通常以系统 **RMS 误差**表述。

## 1. 三种基本定位途径

（a）单站测向 + 多次观测（三角定位）；（b）多站测向交会（三角定位）；（c）**精确（precision）
定位系统**——用 TDOA/FDOA，精度最高。角度测量是基础。

## 2. 角度测量技术及其典型精度

- **旋转定向天线**：机械/电子旋转定向天线测向。
- **多天线幅度比较**。
- **Watson-Watt 技术**：中等 DOA 精度（约 2.5° RMS）。
- **多普勒技术**：机载常用，典型 **3° 或更差 RMS**。
- **测距技术**：精确定位技术之一的基础（见 §3）。
- **干涉仪测向**：
  - 两天线构成**基线**，与波前、方向构成**干涉仪三角形**；D 与基线长之比即角 A 的正弦，
    角 A = 角 B（垂直于基线的方向为参考）；到达角还须计入基线取向。
  - **单基线**干涉仪基线取 **0.1λ–0.5λ**（<0.1λ 无优势）；用高前后比天线或多基线解模糊
    （六天线阵可得六条基线，正确到达角在各基线数据间相关）。
  - **相关型干涉仪**：用 >0.5λ 基线，靠多条基线数据相关解模糊。
  - **多基线精确干涉仪**：同时采集三条或以上、长于多个半波长的基线数据（两条基线相位差不同）
    以解模糊，精度可达约 1° RMS。

## 3. 精确辐射源定位技术：TDOA 与 FDOA

精确定位技术指高精度者，常用 **到达时间差（TDOA）**与**到达频率差（FDOA）**，常配合使用。

- **TDOA（到达时间差）**：
  - 两接收站构成**基线**；相对距离差决定辐射源所在的一条**双曲线等时线（hyperbolic
    isochrone）**；至少两条基线（**需三个接收站**）才得两条双曲线交点定辐射源位置。
  - **脉冲辐射源定位**：须把各站到达时间数据送到处理点算 TDOA。
  - **模拟辐射源定位**：因需大量采样，TDOA 对模拟信号相对较慢。
  - 也可用**多普勒原理**测相对（距离）变化率。
- **FDOA（到达频率差）**：实现精确定位的重要技术；**对运动辐射源**另有要点（FDOA 对运动
  发射机的适用）；**FDOA 与 TDOA 联合**可提高精度/解算。

## 4. 定位精度度量

- **RMS 误差**：任何 DOA 或定位测量都有误差。若要求每次测量都小于某角度误差，则规定**峰值误差**；
  但实用测向系统（尤其瞬时 360° 覆盖者）会因少数角度/频率处的外部低电平干扰或点反射而产生与
  系统性能无关的**峰值大误差**。故通常以 **RMS 误差**代表系统有效精度：在全角度（360°）与全频率
  范围多点测量，每测得角与真实角比得误差角，`error_RMS = √[Σ(error_i²)/n]`。
- **圆概率误差（CEP）**：源自炮兵/轰炸术语（半数弹着点在其中的圆半径）。定位系统中 CEP 是
  **以计算辐射源位置为圆心、含 50% 概率真值的圆半径**（亦有 90% CEP）。
  - 理想几何（两 DF 站相对辐射源等距且呈 90° 视角）下：设各站误差正态零均值，RMS 误差线含
    68.2% 读数（正态曲线到 1σ 的面积 0.341）；恰好内切于 RMS 线的圆含 **46.5%** 概率
    （0.682² = 0.465）；把圆半径增到 **1.037 倍**则含 50%（到 1.037σ 面积 0.3536，[0.3536×2]² = 0.5）。
    亦即真值落在 ±1.037σ 内的概率为 70.7%，两站同时满足则为 0.707² = 0.5。
- **椭圆概率误差（EEP）**：几何较差（非 90° 视角）时用椭圆，尺寸为内切椭圆的 103.6%，
  同样可定义 50% 或 90%。

## 5. 定位误差预算

定位系统最重要的价值度量是定位精度；系统规格中须列误差预算。

- **误差合成**：**独立随机**误差按平方和开方合成：
  `Total RMS error = √(error₁² + error_₂² + … + error_n²)`；**非随机**误差则直接相加。
  RMS 误差 = 均值误差与标准差之组合；在可精确测量系统误差处（如仪表测量场），可把均值误差先行
  偏置掉，则 RMS =标准差（假定主要误差源于平台——机载 DOA 系统常如此，因机身反射引起显著 DOA
  误差、远处多径反射器误差较小）。
- **反射对 AOA 误差的影响**、**站点位置精度**、**AOA 定位的误差预算各项**、
  **SNR 相关误差**、**校准误差**、**AOA 系统误差的合成**。
- **AOA 误差换算定位误差**：测量精度、CEP 等；**精确定位系统（TDOA/FDOA）的定位误差**分别有
  专门分析。

## 6. 作战意义与研究价值

- RMS/CEP/EEP 三种度量与误差平方和合成，是把测向精度“翻译”为**目标定位精度**、进而决定
  打击手段（炮兵/精确制导）选择的通用标尺。
- TDOA/FDOA 精确定位技术是冷战后 SIGINT/ESM 精确定位能力的核心，连接 [[sead|SEAD]] 的
  精确目标定位需求（CEP 与“笨弹/炮兵 100 m”级精度对应，见 [[emitter-location|定位页]]表）。
- 误差预算与校准（按型号/序列号）是理解历史测向系统能力边界与实战精度的框架。
