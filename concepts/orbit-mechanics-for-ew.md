# 电子战轨道力学（Orbit Mechanics for EW）

技术参考层页面。Adamy《EW 105》Ch3 汇总的**地球卫星轨道力学**中与 EW 相关的部分：开普勒轨道根数、
轨道尺寸-周期关系、星下点（SVP）、地面目标的视距角/方位/距离/仰角、以及**地平线距离/角**。这是
本库电子战技术层新增的**空间 EW 底座**。作为技术参考，不作为具体历史事件的史料。

> 卫星因位置高、可视距离远、可长期运行而成为有价值的 EW 平台；劣势是无人、须靠电磁链路通信
> （易被对抗）、难以机动到最优位置。**轨道选择的核心权衡是卫星到潜在截获/干扰目标的距离**
> （卫星很远，故传输损耗极大）。

## 1. 开普勒轨道根数（Keplerian Ephemeris，Table 3.1）

卫星相对地球的位置由**六个**根数定义：

| 根数 | 含义 |
|---|---|
| **a** 半长轴（semi-major axis） | 轨道**尺寸**（椭圆长轴之半，亦为卫星到地心的平均距离；圆轨道即轨道半径） |
| **e** 偏心率（eccentricity） | 轨道**形状**（0–1；圆轨道 e=0）。近地点距地心 a(1−e)、远地点 a(1+e) |
| **i** 倾角（inclination） | 轨道相对赤道面的**倾斜**（决定轨道覆盖的最大纬度；赤道卫星 0°、极轨 90°） |
| **n** 升交点赤经（right ascension of ascending node） | 卫星向北过赤道处经度与**春分点方向**之间的角 |
| **w** 近地点幅角（argument of perigee） | 升节点与近地点之间的角（在轨道面内） |
| **v** 真近点角（true anomaly） | 近地点与卫星在轨道上位置之间的角 |

- 轨道是椭圆，**地心在椭圆的一个焦点上**。
- 圆轨道高度恒定 = 轨道半径 − 地球半径。

## 2. 轨道尺寸与周期的关系（开普勒第三定律）

`a³ = C·P²`（a 半长轴、C 常数、P 周期）。由圆轨道求 C：例：周期 1.5 h、高 281.4 km（半径
6,653 km）→ `C = 6653³/90² = 36,355,285 km³/min²`。

- **表 3.2/图 3.3**：圆轨道卫星高度 vs 周期（1.5–9 h）。例：周期 300 min → 高 **8,473 km**。
- **静止（synchronous）卫星**：周期 = 23 h 56 min 4.09 s（约 **1,436 min**，因地球每年自转 366 次
  以面向太阳 365 次）→ 半径 **42,165.7 km**、高度 **35,795 km**；可对一点悬停、可见约 **45%**
  地球表面。
- **GPS**：12 h 轨道、半径 26,612 km（高度 20,241 km），每天两圈。
- 低轨（贴大气层上）周期近 **1.5 h**、对单一目标驻留仅**几分钟**、可视约 **2,000 km**（自 SVP 起）。

## 3. 星下点（SVP）与地面位置

- **SVP（sub-vehicle point）**：卫星正下方地球表面的点＝地心到卫星连线与地表交点。SVP 纬度＝赤道
  到 SVP 的地心角；SVP 经度＝过 SVP 与过格林尼治的经线间角。
- **经线**是大圆段（所在平面过地心）；**纬线不是大圆**，但纬度定义为赤道以北/南的角度。
- **地面位置**：把卫星（发）与地面（收）两点的经纬度连同**北极**构成**球面三角形**——角 A 在北极、
  角 B 在 SVP、角 C 在接收点；边 c = 90°−SVP 纬度、边 b = 90°−接收点纬度、边 a = SVP 与接收点间的
  **地心角**。
- **传播距离**由卫星-目标-地心构成的**平面三角形**求得（余弦律）。

## 4. EW 威胁定位（Ch3.7）

- **视距角（look angles）**：由北极、SVP、威胁位置构成球面三角形，用**球面余弦律**求地心角
  `cos(a) = sin(lat_SVP)sin(lat_threat) + cos(lat_SVP)cos(lat_threat)cos(ΔLong)`。
- **方位**：计算指向威胁的方位（球面三角/平面三角）。
- **距离与仰角**：由卫星-威胁-地心平面三角形求（余弦律）距离，及仰角。
- 卫星与地面威胁的相对位置是 EW 方程的关键输入——截获/干扰效能高度依赖该几何。

## 5. 地平线距离与角（Ch3.8）

卫星、地心、地平点构成**平面直角三角形**（地平点处向量与切面成 90°）：

- **传播距离** `c = √(b² − a²)`（a = 地球半径、b = 卫星到地心距离 = 高 + 地球半径）。
- **地心角** `C = arcsin[(c·sinB)/b]`（B=90°）；仰角（自天底）= 90° − C。
- **地表距离** = `40,030 km × (地心角/360°)`（地球大圆周长 40,030 km）。
- **算例**：3 h 周期、高 4,189 km、半径 10,560 km → 到地平线链路距离 `√(10560²−6371²) = 8,422 km`；
  地心角 52.89°；地表距离 5,881 km。若目标直线距离 5,193 km < 8,422 km，则**卫星可见目标**。
- **表 3.3**：各周期圆轨道卫星的高度、半长轴、到地平线直线距离、SVP 到地平线的地表距离。
- 低轨（如 300 km）卫星对地面目标的地平线地心角 `C = arccos(R_E/(R_E+H))`（例：300 km → 17.2°），
  对应地表距离约 1,913 km、链路距离约 1,973 km。

## 6. 作战意义与研究价值

- 轨道根数与“轨道尺寸-周期”关系，是把卫星位置/可见性量化为 EW 输入（链路距离、驻留时间）的基础。
- SVP + 球面三角形求地心角/方位/距离/仰角，是**空间截获与空间干扰所有算式**的几何前置。
- 地平线距离/角界定卫星的**可见范围**，直接决定空间截获（[[intercept-from-space|Ch9]]）与空间
  干扰（[[jamming-from-space|Ch10]]）的可行性。
- 静止轨道（可见 45% 地表、可悬停）vs 低轨（驻留几分钟、可视约 2,000 km）的对比，是空间 EW 平台
  选择的核心权衡。
