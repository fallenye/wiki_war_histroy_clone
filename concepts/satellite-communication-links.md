# 通信卫星链路（Communication Satellite Links）

技术参考层页面。Adamy《EW 102》Ch7 汇总的**通信卫星链路术语、噪声温度、链路损耗、链路性能计算、
与 EW 链路方程的关系、卫星链路干扰**。这是 EW 101 概念层未覆盖、由 EW 102 新增的领域。作为技术
参考，不作为具体历史事件的史料。EW 101 基础（dB、链路方程）见
[[ew-link-equation-and-db-math|链路方程与 dB 数学]]。

## 1. 通信卫星的性质

通信卫星在地面终端之间传递信息；链路的各项性能须分别对**上链（uplink）、下链（downlink）**以及
两端终端之间的**整条路径**定义。

## 2. 术语与定义（Table 7.1/7.2）

- **EIRP（等效各向同性辐射功率，dBW）**：为使波束峰值处达到此有效辐射功率、须输入一个各向同性
  （单位增益）天线的功率。**天线指向误差单独处理**。
- **G/T_s（接收机品质因数，dBi/K）**：天线增益除以接收系统噪声温度，以对接收机最有意义的量表示；
  直接与接收信号质量相关。
- **Q（系统品质因数）**：把 EIRP 与接收机品质因数结合（EIRP + G/T_s），与接收信号质量相关。

## 3. 噪声温度

接收机灵敏度不用“噪声温度”本身，但**接收系统噪声温度**是必算项。

- **系统噪声温度**：`T_S = T_ANT + T_LINE + (10^(L/10))·T_RX`（T_S 系统噪声温度 K；
  T_ANT 天线噪声温度；T_LINE 馈线噪声温度分量；T_RX 接收机噪声温度；L 馈线损耗 dB）。
- **天线噪声温度（T_ANT）**：由落入天线波束内的东西决定——指向太阳时噪声温度极高；波束完全被
  地球或雨占据时天线温度较高；给出随仰角变化的曲线。
- **馈线温度（T_LINE）**：`T_LINE = [10^(L/10) − 1]·T_M`（L 接收机前损耗 dB，T_M 损耗机构的环境
  温度，典型 290 K）；常写作 `T_LINE = [T_ANT + (L−1)T_M]/L`（L 为线性衰减）。
- **接收机噪声温度（T_RX）**：由噪声系数换算 `T_RX = T_R·[10^(NF/10) − 1]`（T_R 参考温度，典型
  290 K；NF 接收机噪声系数 dB）。给有**噪声系数-噪声温度对照表**（0 dB→0 K、1 dB→75 K、
  2 dB→170 K、3 dB→289 K、5 dB→627 K、7 dB→1,163 K……）。级联时首级噪声温度占主导：
  `T_e = T_1 + T_2/G_1 + …`。
- **算例**：三级接收机系统噪声温度 = 30 K + 261 K + 699 K = **990 K**（由首级主导）。

## 4. 链路损耗

- **扩散损耗（spreading loss）**：以两各向同性天线间的传递函数计算（同 RF 扩散损耗公式）。
- **大气损耗**：仰角越低损耗越大（路径穿整个大气层）；例：10 GHz 时 0° 仰角约 **3 dB** 大气损耗。
- **雨雾衰减（rain and fog attenuation）**：从 0°C 等温线到地面站沿链路路径的雨衰减。
- **法拉第旋转（Faraday rotation）**：信号穿过电离层时极化面旋转，影响星-地链路。
- **典型链路**：对同步卫星链路与低轨（LEO）链路分别计算。
- **链路性能计算**：分别针对同步卫星链路与低轨链路。

## 5. 通信卫星链路与 EW 链路方程的关系（Ch7.7）

- 地面（terrestrial）链路在多数 EW 应用中假定所有分量与落入天线波束内的角区均为 **290 K**；
  卫星链路则用**噪声温度**精细区分（天线/馈线/接收机）。
- **ERP vs EIRP**：地面链路说离开发射天线的 ERP = 发射功率 × 天线增益（dB 相加），隐含“天线峰值
  增益指向接收机”；EW 中常不成立，故 EW 链路的 ERP **须含指向接收机方向的天线增益**。
  **COMSAT 链路用 EIRP**（定义为使波束峰值处达此有效辐射功率所需输入各向同性天线的功率），
  天线指向误差单独处理。
- **损耗差异只在适用范围**：地面链路的**大气损耗/km**在整条路径上通常视为常数；COMSAT 链路因
  穿过整个大气层，故对给定频率与仰角是一个**固定损耗量**。雨损耗：地面链路取决于雨密度与路径
  雨密度廓线模型；SATCOM 链路只受 0°C 等温线以下到地面站那段路径的雨影响。两者扩散损耗均用
  视线传播模型；但地面链路在微波以下可用不同传播模型。
- **功率/灵敏度表达差异**：地面链路有时用接收位置处的**场强（µV/m）**或 dBm（用理想各向同性天线
  的假定功率）；COMSAT 链路用照明度“**W（dBW/m²）**”。地面链路的接收功率定义为离开天线进入
  接收系统的功率，灵敏度 = kTB × 接收机噪声系数 × 所需预检 SNR（常称 **C/N**，亦称 RFSNR）；
  解调输出质量以 SNR（dB）描述。COMSAT 链路则对**照明度**应用**接收机品质因数**（天线增益/接收
  系统噪声温度），得**载波-噪声温度比（与接收机带宽无关）**，再施加带宽得**载噪比 C/N**。

## 6. 卫星链路的干扰（Ch7.8）

- 与任何干扰一样，**要干扰的是接收机而非发射机**。雷达收发同址使此点易被混淆；SATCOM 链路正相反
  ——收发相距甚远。
- 多数卫星链路是**双向**的，故**定位发射机即可推知（不辐射的）接收机位置**。这很重要，因所涉
  距离使干扰常须用**定向干扰天线**。
- COMSAT 信号几乎总是数字调制，故 [[ew-against-communications|对通信的 EW]]中关于干扰数字信号的
  讨论适用。
- **下链干扰（downlink jamming）**与**上链干扰（uplink jamming）**分别有要点。

## 8. 卫星链路几何与链路类型（据 EW 105 增量）

[[sources/ew-105-adamy|EW 105（空间 EW）]] 从空间 EW 视角补充卫星链路的**几何与类型学**：

- **链路几何**：卫星“**向下看**”（求到地面点距离）与地面“**向上看**”（求仰角/方位，由
  地面站-卫星-地心平面三角形）；须分别计算链路**相对地面控制站**与**相对敌截获站**的角度。
- **上行链路**：**指令链路**（地面站→卫星；带宽低但可为纠错增大；须确保正确接收）、**拦截链路**
  （敌发信机→卫星载荷接收机，`P_R = P_T + G_T − 链路损耗 + G_R`）。
- **下行链路**：**遥测**、**数据**、**面向数据用户**、**干扰**链路（同式）。
- **敌对链路**：敌地面干扰机扰上行、敌机载干扰机扰下行、敌接收机截获上/下行。
- 星-地链路**特有损耗**（EW 105 Ch5）：LOS 损耗、大气损耗（随仰角）、**天线失配 `ΔG = 12(θ/α)²`**、
  极化损耗（法拉第旋转、圆-线 3 dB）、雨衰（0°C 等温线）。
- 详见空间 EW 专页：[[satellite-links|卫星链路]]、[[space-radio-propagation|空间无线电传播]]、
  [[satellite-link-vulnerability|卫星链路脆弱性]]。

## 9. 作战意义与研究价值

- 噪声温度体系（天线/馈线/接收机 + 级联首级主导）与 G/T、EIRP、Q 等品质因数，是理解卫星通信
  链路预算与抗干扰余量的通用工具，跨冷战至今通用。
- “EW 链路（ERP 含指向方向增益）vs COMSAT 链路（EIRP + 指向误差单列 + 噪声温度精算）”的对照，
  澄清了两套工程语言的联系与差异。
- 双向链路可由发射机定位推知接收机位置、SATCOM 数字信号适用通信干扰理论，连接
  [[emitter-location|定位]]与 [[ew-against-communications|通信 EW]]。
- EW 105 的链路几何与类型学把通信卫星链路纳入更广的**空间 EW** 框架（截获/欺骗/干扰上/下行，
  见 [[satellite-link-vulnerability|链路脆弱性]]）。
