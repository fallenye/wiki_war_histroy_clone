# 阿拉伯军团在 1948 年的表现（Pollack 的评价）

> 单源：[[sources/arabs-at-war-pollack|Pollack]] ch3（Jordan）。与 Herzog 的军团叙述（
> [[concepts/arab-legion-1948]]）方向一致、理由更细，**两页并列**。

## 总判

- Pollack 的原话：阿拉伯军团对新生以色列军队的作战，是"**现代史上任何阿拉伯军队对任何对手
  表现最好的一次**"；在阿拉伯各国军队中"**只有军团像一支现代的职业军队那样作战**"（ch3）。

## 逐项评价（本书所列强项）

| 项目 | 评价 |
|---|---|
| 部队凝聚力 | 出色：单位在最严酷压力下仍保持建制、守住阵地（举例：**第二次 Latrun 之战**）|
| 个人勇气 | 高，以约双方都有大量记载 |
| 合成兵种 | 步兵、装甲车、炮兵的整合"比以色列人做得更好" |
| 射击技术 | "非常高"，由此"经常在交火中压过对手" |
| 反击 | 通常时机好、有进攻性 |
| 侧翼保障 | 好；被以军迂回时"不会瘫痪" |
| 巡逻 | 持续巡逻，常使以军无法达成奇袭，甚至数次反过来奇袭以军 |
| 基层主动性 | 有真正的主动性，抓住转瞬即逝的机会——例：**趁以军对 Latrun 警署防守薄弱时予以攻占** |
| 战术反击 | 时机与效果常是战斗的决定因素 |
| 战役级机动 | 军官经常使用机动，尽管战术层不少进攻只是正面强攻 |

## 两个必须加上的限定（Pollack 的自我约束）

1. **它并不因此算"军事史上的伟大战役"**（ch3）：
   - 对手并不强：1948 年的 Haganah 是"一支很平庸的力量"——单位水平参差，
     装备与训练不足，政治内斗，人员与语言混杂，武器型号杂乱不兼容；
     部分 Haganah 单位**不注意侦察**，因此被约军奇袭；
   - 约军守的是犹地亚—撒马利亚的"极好防御地形"，以军多须自海岸平原仰攻中部山地；
   - 以军还要同时对付另外五支阿拉伯军队，无法对约军集中决定性兵力。
   - **即便如此，约军也只打成平手**（ch3）。
2. **英国军官团是决定因素**（ch3）：
   - 本书引 **El-Edroos** 准将：1948 年及 1951—56 年边境战争期间军团优异表现的功劳
     "应归于 Glubb Pasha 以及自 1921 年建军至 1956 年撤离的在军团服役的英国军官团"；
   - 引 **Trevor Dupuy**：约旦军事效能的主要来源是"**数十年的英国领导与军事传统**"；
   - Pollack 自己的判断：约军的进攻性反击、战场机动、灵活作战、机会性主动，
     全部由（英国主导的）军官团实施；其高超的单兵技能（如射击）直接源于英式
     "长期服役职业兵＋铁一般纪律＋长期训练"的取向。

## 战果的边界（本书所列）

- 约军对以军的**预设防御阵地**几乎总能取胜（以军在耶路撒冷地区成功的进攻——Lod、Ramla、锡安山——
  多是针对**很小的军团部队**；旧城与 Latrun 的较大约军部队顶住了以军多次强攻）；
  而"几乎所有这些情况，以军的进攻都是笨拙的正面强攻，正好落入约军下怀"（ch3）。
- 约军自己的进攻战果有限：主要收获是 **Etzion 集团、旧城犹太区、Sheikh Jarrach 区**，
  且都发生在战争前三周、第一次停火之前，规模都不大（ch3）。
- 这些胜利的对手都不大：例如 **Sheikh Jarrach** 是军团一个步兵营＋炮兵与装甲车，
  击败 **70 名** Irgun 步兵——"这不算匹敌，军团的胜利不能当作其真实战力的证明"（ch3）。
- 一旦遇上训练更好或规模更大的以军部队（**Mandelbaum 门地区、Notre Dame**），约军进攻就毫无进展（ch3）。

## 与 Herzog 叙述的关系

- Herzog 也把军团评为"最有效的阿拉伯军队"，并给出 Notre Dame（200 名步兵近半伤亡）、
  Latrun 四次防守、Radar Hill 等具体战例；但他把原因归于"英国纪律＋贝都因品质＋Glubb 的个人权威"
  （[[concepts/arab-legion-1948]]）。
- Pollack 的补充是**规模的解释**：军团小，所以能精选官兵；服役期长，所以能长期训练（见
  [[concepts/arab-tactical-leadership]]）。
- 两书对同一战役的损失与兵力数字常有差异，本库分别记在各自页面，不合并。

## 1948 年之后的走向（本书的对照）

- Pollack 的判断：约旦军队在 **1948 年处于其效能的顶点**，此后四十三年"一直在努力维持熟练度"
  （见 [[concepts/jordan-army-decline-pollack]]）。
