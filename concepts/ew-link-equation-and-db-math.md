# 电子战链路方程与 dB 数学基础

技术参考层页面。Adamy《EW 101》以**链路（link）**为分析一切雷达、军用通信、信号情报与
干扰系统的最小单元：任何一条链路＝一个辐射源＋一个接收装置＋电磁能量从源到接收机之间的
全部过程。本页把该书的 dB 运算、单向链路方程、传播损耗、接收灵敏度、有效距离、雷达距离
方程的“链路化”形式、干扰信号比及球面三角工具做**可跨战争、跨装备复用**的公式与关系汇总，
不进入教材章节复述，也不代替具体历史事件的史料证据。

> 该书所有 dB 形式的公式中“fudge factor”（如 32、32.4、39 等）来自把物理常数与单位换算
> 合并后取整，**只有输入单位恰当时才成立**：距离 km、频率 MHz、RCS m²、功率 dBm。这是最
> 容易用错之处。

## 1. dB 运算基本约定

- **线性值 → dB**：`N(dB) = 10 log10(N)`；**dB → 线性**：`N = 10^(N(dB)/10)`。
- dB 是**比值**（对数化），故绝对值须先除以某个约定参考量：dBm＝功率／1 mW；dBW＝功率／1 W；
  dBsm＝面积／1 m²（天线有效面积与 RCS 常用）；dBi＝相对**各向同性**天线增益（0 dBi＝全向）。
- 运算便利规则：乘→加对数、除→减对数、m 次方→对数乘 m、开 n 次方→对数除 n。实践中**尽量
  早转 dB、尽量晚回线性**，很多常用答案直接留在 dB。
- dB 方程三种常见形式：`A(dBm)+B(dB)=C(dBm)`；`A(dBm)−B(dBm)=C(dB)`；
  `A(dB)=B(dB)+N·log(线性数)`（N 为 10 的倍数，用于出现平方或更高次项的情形，如传播损耗）。

## 2. 单向链路方程（One-Way Link / 基本通信链路）

线视距、好天气链路：接收电平＝发射功率(dBm)＋发射天线增益(dB)−链路损耗(dB)＋接收天线增益(dB)。

- 信号离开天线后的功率称**有效辐射功率 ERP**（常以 dBm 表述）；天线增益可正可负（全向＝0 dB）。
- 链路损耗先只含**扩散损耗**与**大气损耗**。

### 2.1 扩散损耗（Spreading / Space Loss，对两个各向同性天线）

`Ls (dB) = 32.4 + 20 log10(d_km) + 20 log10(f_MHz)`

- 常数 32.4（本书亦常取整为 **32** 用于 1-dB 精度）由球面积／全向天线有效面积之比导出；
  单位必须是 km 与 MHz。该值是**两个全向天线之间**的损耗，天线增益作为独立项另加。
- 大气衰减非线性，按频率查图表（该书图 2.3）：低频战术点对点通信常可忽略，**高微波与毫米波
  以及穿整个大气层的星-地链路则显著**（例：50 GHz 约 0.4 dB/km）。

### 2.2 接收灵敏度与链路裕度

接收灵敏度＝接收机能正常输出所需的最小信号电平。若接收电平 ≥ 灵敏度则链路可用；接收电平
高出灵敏度多少 dB 即称**链路裕度（margin）**。设接收功率＝灵敏度，可反解出**有效距离**（示例
在 100 MHz、忽略大气损耗下求得 191 km）。

### 2.3 “ether waves”约定与 µV/m 换算

严格说 dBm 只在导线／电路内有定义，空间传播中的信号应以**电场强度 µV/m** 描述。该书用一个
假想的**理想单位增益（全向）天线**置于所论空间点，把该点信号折算成 dBm 以套用链路算术——这是
工程惯例而非物理严格量。测向等天线-接收机强耦合设备常直接以 µV/m 给灵敏度，dBm 与 µV/m 之间
有基于“全向天线有效面积随频率变化”的换算公式（书中给出成对公式及其物理推导）。

### 2.4 近地低频链路

当天线贴近地面且链路超出**菲涅尔区**时，扩散损耗改用双径形式：
`Ls = 120 + 40 log10(d_km) − 20 log10(h_T) − 20 log10(h_R)`（h 为发射/接收天线高度，m）；
菲涅尔区距离由天线高度与频率决定（`FZ = (h_t·h_r·f)/24,000`，FZ km、h m、f MHz）。

### 2.5 刀边衍射（KED）与天线有效高度（据 EW 103 增量）

[[sources/ew-103-adamy|EW 103]] 对通信传播损失补充两点：

- **刀边衍射（Knife-Edge Diffraction, KED）**：当传播路径接近或未完全越过山脊时，在视线损耗
  之上**额外加一项 KED 损耗**（用诺谟图计算，须先算距离项 `d = [√2/(1+d1/d2)]·d1`，d2≥d1），
  KED 损耗**加到视线损耗上**（此处只给诺谟图法，不逐式展开）。
- **天线有效高度**：**鞭状天线的有效高度取其底部（安装面）高度**，是传播方程的重要输入；机载
  单极天线的有效高度同理。这点对通信链路预算有实际意义。

## 3. 雷达距离方程的“链路化”形式（EW 视角）

雷达人惯用聚焦“雷达做得多好”的形式；EW 视角更利于把雷达距离方程拆成**若干链路**逐段核算
功率（dBm）与增益/损耗（dB），从而回答“要把多少干扰功率送进雷达接收机才能抵上目标回波”。

- 发端至目标：`P_T = ERP − 32 − 20 log(D) − 20 log(F)`（D 为到目标距离 km，F 为 MHz）。
- 目标反射（RCS 反射因子）：`P_R = P_T − 39 + 10 log(σ) + 20 log(F)`（σ 为 RCS，m²）。
  该反射因子表达式在 **Ch10（诱饵）**有更详细推导。
- 目标回报至雷达：`P_A = P_R − 32 − 20 log(D) − 20 log(F)`，接收端再加雷达天线增益 G：
  得整式 `P_D = P_T + 2G − 103 − 40 log(D) − 20 log(F) + 10 log(σ)`。

## 4. 干扰信号差（Interfering Signals）

同一接收天线上两个同频信号（一为期望、一为干扰；干扰无论无意或有意同理）的功率差：
`P_S − P_I = ERP_S − ERP_I − 20 log(D_S) + 20 log(D_I)`。
这是**未计方向性接收天线**的最简形；方向性天线会给两信号不同增益因子，是后续 J/S 公式的基础。

## 5. 球面三角（Spherical Trigonometry，EW 建模必备）

该书强调球面三角处理三维问题时以“传感器视角”表达空间关系，**第 11 章建模仿真必然用到**。要点：

- 球面三角形建立在**单位球**上，三条“边”是过球心的大圆；边与角均以度计；球面三角形某些性质
  不同于平面三角形（例如三角可均为 90°）。
- 常用三式：**正弦律** `sin a/sin A = sin b/sin B = sin c/sin C`；**边的余弦律**
  `cos a = cos b cos c + sin b sin c cos A`；**角的余弦律** `cos A = −cos B cos C + sin B sin C cos a`。
- **直角球面三角形**可用 **Napier 规则**简化（五段圆，注意三个“co-”须换余函数）。
- EW 应用四例：
  - **仅测方位 DF 因仰角引起的方位误差**：`cos(Az) = cos(M)/cos(El)`，误差 `= M − acos[cos(M)/cos(El)]`。
  - **多普勒频移**（收发双方各有任意速度矢量）：求各自速度矢量与收发连线的夹角，
    视线距离变化率 Verr＝V_T·cos(角@发)＋V_R·cos(角@收)，`Δf = f·Verr/c`。
  - **三维交战的观测角**：用于把威胁符号摆上头显 HUD（由到滚转轴的角距与局部垂直偏角合成）。
  - 导航（经纬度）与角度-离轴换算等。

## 6. 作战意义与研究价值

- 链路方程是**干扰规划、威胁规避、侦察灵敏度设计**的共同标尺；该书自述掌握单向链路方程与
  雷达距离方程的 dB 形式后，可在脑中（1-dB 精度）快速估算 EW 问题、检查“是否违反物理定律”。
- dB 化把相差多个数量级的量拉到同一标度，使跨战争、跨装备的**参数比较**成为可能（本库各装备
  页的功率、增益、波段等可据此做同标度对照）。
- 球面三角与链路方程是后续 **J/S、烧穿距离、测向定位、仿真建模**各页的数学底座。
