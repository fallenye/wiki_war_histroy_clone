# EW 接收机体制分类

技术参考层页面。Adamy《EW 101》所给 EW 系统**九类接收机**及其能力取舍，是可跨战争、跨装备
复用的分类学。本页汇总各类的定义、机理与参数权衡，用于理解与选型，不作为具体型号的史料。

理想 EW 接收机应能以极好灵敏度 100% 探测全频段全信号、能在强信号中解出弱信号、还能同时
处理多信号并解调——现实中不存在。故复杂系统多**组合多种体制**以匹配预期信号环境。

## 九类接收机及其一般特性（Table 4.1）

| 体制 | 一般特性 |
|---|---|
| Crystal video（晶体检波视频） | 宽带瞬时覆盖；灵敏度低、无频率选择性；主要对脉冲信号 |
| IFM（瞬时测频） | 覆盖/灵敏度/选择性与晶体视频类同；可**测频** |
| TRF（调谐射频） | 类晶体视频，但提供频率隔离、灵敏度略佳 |
| Superheterodyne（超外差） | **最常用**；选择性与灵敏度好 |
| Fixed tuned（固定调谐） | 选择性与灵敏度好；专对单一信号 |
| Channelized（信道化） | 兼具选择/灵敏度与宽带覆盖 |
| Bragg cell（布拉格盒） | 宽带瞬时覆盖；动态范围低；可同时多信号；**不解调** |
| Compressive（压缩） | 提供频率隔离；可测频；**不解调** |
| Digital（数字） | 高度灵活；可处理参数未知信号 |

## 能力矩阵要点（Table 4.2 概述）

各类在“收脉冲 / 测频 / 选择性 / 同时多信号 / 灵敏度 / 截获概率 / 动态范围 / 解调”诸维度上各有
强弱（原书以 G=好、F=中、P=差 的矩阵给出）。要点：

- **晶体视频 & IFM** 用于中低成本、**高密度脉冲**环境，提供宽频段 100% 覆盖；但**无法体面处理
  同时多信号**——频段内任一强 CW 都会严重削弱其收脉冲能力；灵敏度低，最宜对付强信号。现代系统
  常与窄带体制组合以应付困难情形。
- **固定调谐 & 超外差**为窄带，常与其他体制组合以**隔离同时信号、提升灵敏度**；TRF 亦能隔离
  同时信号。代价：任一瞬时只覆盖很窄频谱，**收到非预期信号的概率低**。
- **Bragg cell & 压缩**：宽频段瞬时覆盖、可同时多信号，但**不解调**（仅作探测/测频/隔离）。
- **信道化 & 数字**为发展方向，能提供 EW 所需的大部分指标，但尺寸/重量/功率/成本反映元件与
  子系统小型化的当前水平，故常只在复杂系统中承担最难的那部分工作。

## 各体制机理要点（逐类）

- **Crystal video**：最简，晶体（二极管）检波后接视频放大，对一切输入信号做幅度解调并在视频
  放大器内合并输出；常置于带通滤波器后限定频段（如 2–4 GHz），并用**对数视频放大器**获得宽
  动态范围。信号功率低使检波器工作在**平方律**区（输出随输入功率而非电压）；其他体制检波约在
  10 mW 处进入**线性区**。灵敏度经验值：现代自动处理（需 ≥15 dB SNR）下约 **−40 ~ −45 dBm**；
  加前置放大（最优增益）可改善到 **−65 ~ −70 dBm** 级。强带内 CW 会与所有脉冲合并、使视频输出
  幅度失真。
- **IFM**：基本 IFM 电路产生一对随射频变化的信号，数字化后给出直接数字频率读数；输入带限，
  延时线决定其输出范围。
- **Superheterodyne**：混频到固定中频（IF）后滤波放大，故选择性/灵敏度好，是系统中最常见的
  基础体制。
- **Channelized**：把宽带分成许多窄信道并行处理，兼得宽带覆盖与窄带选择性。
- **Bragg cell / Compressive**：利用声光/色散器件在宽瞬时带宽上并行给出频域分布，长于探测与
  测频，不作解调。
- **Digital**：可编程、可处理未知参数信号，灵活度最高，但受限于当代器件规模/功耗。

## 灵敏度、动态范围与系统配置（据 EW 103 增量）

[[sources/ew-103-adamy|EW 103]] 对通信接收机的补充：

- **系统灵敏度**：`S = kTB + NF + RFSNR`（kTB 为带宽内热噪声、NF 噪声系数、RFSNR 所需预检信噪比）。
- **数字化**：采样率、数字波形、比较器型 ADC（n 位需 2ⁿ−1 个比较器，如 8 位 255 个）、**I&Q
  数字化**（同相/正交，确定频率与相位）。
- **数字化信号质量问题**：**码片检测（chip detection）**与**截获跳频信号**（跳频台信号在 I&Q
  A/D 中数字化；用并行 I&Q 采样 + 信道化器，须采足够 I&Q 样本以覆盖所需信道数）。
- **系统动态范围**：**模拟 vs 数字动态范围**、模拟接收机动态范围（含杂散/互调）、数字动态范围。
  较早的**布拉格盒**动态范围仅约 20 dB（约 1 kW 主功率时），主功率更低则更差。
- **典型接收机系统配置**：多接收机侦察与电子支援（ESM）系统、多接收机系统、**遥控接收系统
  （remote receiving systems）**——把接收机前置到远处降低对己方的干扰/提高生存性。
- 现代数字接收机可执行此前不切实际的任务（如**码片检测与跟随**）。

## 作战意义与研究价值

- 接收机体制决定了 **ESM/ELINT/RWR** 的截获概率、灵敏度和可测参数；理解“宽带瞬时 vs 窄带
  选择”这一对根本取舍，可解释许多历史装备的设计选择（如越战 RWR 的频段与截获取舍）。
- 与 [[sigint|SIGINT]]（收集侧）、[[sead|SEAD]]（对抗侧）互参：接收机是侦察与告警环节的入口。
- “信道化/数字为方向”这一判断为理解冷战后 EW 数字化提供了框架；灵敏度/动态范围/遥控配置把
  接收机与 [[communications-search-and-poi|通信搜索]]、[[communications-intercept|截获]]贯通。
