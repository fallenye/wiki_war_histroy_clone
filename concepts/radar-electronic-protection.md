# 雷达电子防护（Radar Electronic Protection, EP）

技术参考层页面。Adamy《EW 104》Ch4 汇总的**新一代威胁雷达的电子防护（EP）技术及其对 EW 的影响**。
EP 是 EW 三大子域之一，但不同于 ES/EA——**EP 通常不含专门 EW 硬件，而是传感器系统内一系列
降低敌干扰效能的功能**（EP 保护的是你的**传感器**，不是平台）。作为技术参考，不作为具体历史
事件的史料；其中引用的具体型号（S-300/SA-10 等）系**本书据开放源叙述的威胁参数**，本页照录并
明确标注来源性质，不当作一手史料。

## 1. 主要雷达 EP 技术及其对抗对象（Table 4.1）

| EP 技术 | 防护对象 |
|---|---|
| 超低旁瓣（ultralow side lobes） | 雷达探测与旁瓣干扰 |
| 旁瓣对消（side-lobe cancellation） | 旁瓣噪声干扰 |
| 旁瓣匿隐（side-lobe blanking） | 旁瓣脉冲干扰 |
| 抗交叉极化（anti-cross-polarization） | 交叉极化干扰 |
| 脉冲压缩（pulse compression） | 诱饵与非相干干扰 |
| 单脉冲雷达（monopulse） | 多种欺骗干扰 |
| 脉冲多普勒雷达（pulse Doppler） | 箔条与非相干干扰 |
| 前沿跟踪（leading-edge tracking） | 距离波门拖引（RGPO） |
| Dicke-Fix | AGC 干扰 |
| 烧穿模式（burn-through） | 所有干扰 |
| 频率捷变（frequency agility） | 所有干扰 |
| PRF 抖动（PRF jitter） | 距离波门拖入（RGPI）与覆盖脉冲 |
| 寻的干扰（home-on-jam） | 所有干扰 |

## 2. 天线旁瓣与超低旁瓣

- 天线方向图近视轴为 **sine(x)/x**，主瓣边缘有零点，其余方向有旁瓣；第一二个旁瓣之后旁瓣由结构
  反射决定，常有大的后瓣；零点比旁瓣窄得多，故取**平均旁瓣电平**即可估计远离主瓣时的收发增益。
- **超低旁瓣**无严格定义，仅指旁瓣远低于常规天线。Schleher 给的范围：
  - “**普通**”旁瓣：低于主瓣峰值 **13–30 dB**，平均旁瓣峰值增益 0 至 −5 dBi；
  - “**低**”旁瓣：低于 **30–40 dB**，峰值增益 −5 至 −20 dBi；
  - “**超低**”旁瓣：低于 **>40 dB**，峰值增益 **<−20 dBi**。
- **EW 影响**：在旁瓣探测未捕获目标的雷达，其探测距离**按旁瓣降低量的平方缩减**；EA（如远距支援
  SOJ）的 J/S 也按旁瓣降低因子缩减。**对策**：ES 优化灵敏度（相控阵接收天线、数字接收机优化带宽、
  或趁雷达主瓣扫过时取信息）；EA 用有源电扫阵（AESA）把波束对准待扰雷达以提高 J/S。

## 3. 旁瓣对消与旁瓣匿隐

- **相干旁瓣对消（Coherent Side-Lobe Cancelling, CSLC）**：可把旁瓣收到的窄带干扰（如典型 FM
  噪声）最多降 **30 dB**——J/S 降该因子，故干扰机须多 30 dB 功率、或近 32 倍、或保护目标 RCS 降
  1000 倍。**对策**：混合脉冲与 FM 噪声干扰——脉冲产生大量类窄带 CW 分量，占用全部对消通道，
  提高干扰效能。
- **旁瓣匿隐（Side-Lobe Blanking）**：当雷达旁瓣定向天线收到的脉冲比主天线强时，雷达在该脉冲的
  1–数微秒内**匿隐主天线输出**。**对策**：把覆盖脉冲定时到覆盖威胁雷达自身脉冲，使雷达"自己干扰
  自己"。

## 4. 单脉冲雷达与抗交叉极化

- **单脉冲（Monopulse）**：从单个脉冲即得角信息，是若干欺骗手段（第 3 章部分手法）无法成功对抗
  的；有些手法反而**增强**单脉冲雷达的角跟踪。**对策**：用第 3 章 §3.4.9–3.4.15 的方法（编队/
  闪烁/地形反射/交叉极化/交叉眼等）。
- **抗交叉极化（Anti-Cross-Polarization）**：以某 dB 级表示；通过**无增益斜削的平板相控阵**降低
  旁瓣、或**极化滤波器**不让交叉极化干扰进入接收机实现。**对策**：除非能造极大 J/S，否则交叉极化
  干扰无效，宜改用其他干扰。

## 5. 脉冲压缩与波形（Chirp / Barker）

- **脉冲压缩（PC）**：若干扰不含雷达的压缩波形（chirp 或 Barker 码），J/S 按**压缩比**缩减——
  **可达 30 dB**。**对策**：在干扰信号上施加压缩波形。线性 chirp 可用扫频振荡器/DDS 等复现；
  **非线性 chirp 或 Barker 码**则须在干扰机内**集成 DRFM**（见 [[digital-rf-memory|DRFM 页]]）。
- **Barker 码**：二相相移键控（BPSK）脉冲用码调制；雷达接收端用与码位数相同的抽头延时线，
  当脉冲正好填满移位寄存器时各比特同相叠加、未对齐时输出近零——把接收脉冲缩短到 1 个码位时长，
  压缩距离分辨率；无 Barker 码的干扰脉冲不压缩，故 J/S 降码位数倍。

## 6. 距离波门拖引（RGPO）与前沿跟踪

- **RGPO**（见 [[jamming|干扰页]]）：干扰机收到脉冲后逐次增时延回发，使目标似在远离。
- **前沿跟踪（Leading-Edge Tracking）**：RGPO 干扰机的**处理时延**使雷达始终只见有效皮肤回波
  （延迟的 RGPO 脉冲永不被看到），故雷达继续跟踪皮肤回波——RGPO 失效。**对策**：用 **RGPI**；
  或把 RGPO 时延缩短到能捕获前沿跟踪器（典型用 **DRFM**，其处理时延极短，约 50 ns）。

## 7. AGC 干扰与 Dicke-Fix

- **AGC 干扰**：干扰机以约雷达 AGC 时间常数的速率发强脉冲，俘获雷达 AGC、降低增益，削弱所有
  带内信号。
- **Dicke-Fix**：含**宽带通道**，把强、低占空比脉冲**限幅**，使其不能俘获后级窄带通道的 AGC。
  **对策**：有专门波形可让干扰信号穿过 Dicke-Fix。

## 8. 脉冲多普勒（PD）雷达的 EP

PD 雷达**固有** EP：①期望回波在窄频范围内，可鉴别**非相干干扰**；②可看到干扰机的杂散输出；
③可看到箔条的频率展宽；④可看到**分离目标**；⑤可关联距离变化率与多普勒频移。

- **处理矩阵**：PD 雷达相干，每脉冲是同一 RF 信号的采样，故可同时测到达时间（→距离）与多普勒
  频移（→径向速度）；处理器形成**距离×速度矩阵**。距离门深 = (脉宽/2)×光速；速度门由滤波器组
  或 FFT 信道化实现；滤波器带宽的倒数即**相干处理间隔（CPI）**。
  **处理增益（dB）= 10 log(CPI × PRF) 或 10 log(PRF/滤波器带宽)**。
- **分离目标（对 RGPO 的免疫）**：真目标回波随距离门递增而落入与真实多普勒一致的速度门；
  RGPO 干扰脉冲虽距离递增，其多普勒频移却由干扰机**真实**径向速度决定，二者不一致——PD 雷达据
  此选择"距离变化率与多普勒一致"的脉冲，继续跟踪真目标、击败 RGPO（对 RGPI 同理）。**对策**：
  干扰机须同时施加**速度波门拖引（VGPO）**，且频偏须与 RGPO 速率协调。
- **相干干扰**：目标相干回波落**单个**多普勒门；宽带干扰（阻塞/非相干点噪声）占**多个**门，雷达
  可鉴别出相干目标回波——故欺骗 PD 雷达须产生**相干干扰**信号。
- **PD 雷达的距离/频率模糊**：最大不模糊距离 `R_U = (PRI/2)·c`；最大多普勒频移
  `ΔF = (v_R/c)·2F`（例：10 GHz 雷达、500 m/s 最大距离变化率 → ΔF ≈ 33.3 kHz）。脉冲信号频谱的
  谱线间隔 = PRF，故 PRF 越低频率模糊越重。
  - **低 PRF**：距离不模糊（大 PRI，宜搜索/截获），但**多普勒高度模糊**→速度测定模糊，易受
    RGPO/RGPI。
  - **高 PRF**：多普勒不模糊（宜高速迎头交战），但**距离高度模糊**（须加 FM 或用速度-only 模式）；
    尾追交战时多普勒低，优势减小。
  - **中 PRF**：距离与速度**皆模糊**，用多个 PRF 各自造模糊区，处理中找出在目标处不模糊者；为增强
    尾追交战而发展。

## 9. 干扰检测、频率捷变、PRF 抖动、寻的干扰

- **干扰检测**：PD 雷达能检测干扰（故可触发 HOJ）。
- **频率捷变（Frequency Agility）**：雷达有多种工作频率。①可选频（长时间选一频）——干扰机只要测出
  在用频率即可优化干扰；②**每次扫描一频**（如螺旋扫描每次圆周扫后换频）——DRFM 可测首脉冲频率并
  精确复制后续脉冲；③**脉间跳频（pulse-to-pulse hopping）**——最难，干扰机无法预知下一脉冲频率。
  例：6 GHz、10% 频率范围（600 MHz）、雷达 3 MHz 带宽——干扰只有 **0.05%** 有效，有效 J/S 相对
  匹配干扰**降 23 dB**。**对策**：DRFM 测首 50 ns 即设定频率（现代雷达脉宽数微秒，损失极小）。
- **PRF 抖动（PRF Jitter）**：伪随机脉冲重复间隔使脉冲到达时间不可预测→**RGPI 不可行**；覆盖脉冲
  须预测脉冲定时也难。**对策**：用**扩展覆盖脉冲**覆盖雷达 PRI 的整个抖动范围。
- **寻的干扰（Home-on-Jam, HOJ，又称 track-on-jam）**：导弹能接收干扰信号并测其到达方向，雷达
  检测到干扰后进入 HOJ、令导弹朝干扰源飞——对**自卫干扰（SPJ）**做终端防护极危险；亦威胁
  **远距支援干扰机（SOJ，高价值/低库存资产）**（导弹可爬升以增程、从上方寻的）。**对策**：自卫
  干扰不宜做终端防护，改用**诱饵**代替（见 [[radar-decoys|雷达诱饵]]）；或用**消耗性干扰机从别处
  干扰**（如 MALDJ 小型空射诱饵，吸引 HOJ 导弹）。

## 10. 威胁系统升级（据本书开放源叙述）

本书以 S-300 家族为主线叙述苏联防空系统升级（明确声明为**开放源**、非机密简报），要点：
冷发射（气体弹出后转向、再点火，5 分钟展开、3–5 秒发射间隔）、"hide, shoot, and scoot"、
EP 增强、垂直发射快速再装填。代表性数据（**本书照录开放源，非一手史料**）：SA-10 初始杀伤距离
75 km→150 km（FLAP LID AESA 火控、超低旁瓣）；舰载 SA-N-6（90 km，末段半主动）；SA-N-20（MACH 6，
track-via-missile）；SA-20（Gargoyl，195 km，气动舵→气动控制）；SA-21（GRAVE STONE/TRIUMF，
240/396/442 km，专打 SOJ 机与空中指挥机）；SA-12（GLADIATOR 75 km / GIANT 100 km 反导）；SA-23
（200 km）；SA-6→SA-11（35 km）→SA-17（50 km）；SA-8（J 波段频率捷变单脉冲、C 波段截获、EO 跟踪）
→SA-15（自主、相控阵 PD）。**MANPADS**（光学瞄准 IR 制导）：SA-7（非制冷 PbS，仅尾追，3,700 m）
→SA-14（致冷、全向，2,300 m）→SA-16（全向、抗照明弹，5 km）→SA-18（致冷 InSb、双通道跟踪、抗
照明弹，5.2 km）→SA-24（6 km、夜视）。**截获雷达升级趋势**：部分跟踪雷达内建截获模式，截获雷达
频率升高（TIN SHIELD/BIG BIRD 至 S 波段、HIGH SCREEN 至 X 波段），以更好对付小 RCS 目标并提升
定位精度与分辨。**AAA 升级**：从 ZSU-23（垂直包线约 1,500 m）到加装热寻的导弹（包线至 10,000 m）
与 30 mm 炮（射程约 23 mm 双倍），后改雷达制导导弹。

## 11. EW 影响小结（4.6 的功能性启示）

对每项升级的功能性影响与"怎么办"（跨型号通用）：

- **杀伤距离增大**→远距支援干扰（SOJ）的 J/S 因 −20 log R_J 项而显著下降（例：SA-2 的 45 km 到
  改进 SA-10 的 150 km，J/S 降约 **13 dB**；到 SA-21 的 396 km，降约 **19 dB**）。对策：增大干扰
  功率、降目标 RCS（但新雷达针对低 RCS 优化）、或改用 **stand-in 干扰**（把无人干扰机放得更近）。
- **超低旁瓣**→探测/干扰距离按旁瓣降低量平方缩减。对策：ES 优化灵敏度/AESA 接收，EA 用 AESA 照准。
- **相干旁瓣对消**→J/S 最多降 30 dB。对策：脉冲混 FM 噪声占满对消通道。
- **旁瓣匿隐**→对策：定时覆盖脉冲使雷达自扰。
- **抗交叉极化**→除非极大 J/S，否则改用他法。
- **脉冲压缩**→J/S 降压缩比（可达 30 dB）。对策：干扰加压缩波形；非线性 chirp/Barker 码须 DRFM。
- **单脉冲**→仅第 3 章特定手法有效。
- **脉冲多普勒**→抑制多个多普勒门内噪声；对策：相干干扰（DRFM）、与 RGPO 配合 VGPO；**块状箔条
  对 PD 雷达已基本无效**。
- **前沿跟踪**→RGPO 失效；对策：RGPI 或用低时延 DRFM 捕获前沿跟踪。
- **Dicke-Fix**→对策：专门波形穿过。
- **烧穿模式**→对策：尽量增大有效干扰功率。
- **频率捷变**→脉间跳频无法预知；对策：DRFM 测首 50 ns 设频。
- **PRF 抖动**→RGPI 不可行；对策：扩展覆盖脉冲覆盖整个 PRI 抖动范围。
- **寻的干扰**→自卫干扰危险；对策：用诱饵/异地消耗性干扰机。
- **改进 MANPADS/AAA**→"飞高即安全"不再成立，须同时依赖 IR 与雷达干扰机（见
  [[infrared-electro-optical-ew|红外与光电 EW]]）。

## 12. 作战意义与研究价值

- EP 技术清单 + 每项的"对策"，构成**新一代威胁对抗的通用决策框架**（不依赖具体型号）。
- PD 雷达的处理增益公式、距离/多普勒模糊、低/中/高 PRF 权衡，是理解现代雷达为何难干扰的定量核心。
- HOJ 使自卫干扰在终端防护中危险、SOJ 威胁高价值平台，解释了**诱饵与 stand-in 干扰机**的崛起。
- 频率捷变/PRF 抖动/脉冲压缩/前沿跟踪等"难缠技术"，正是 **DRFM 成为新一代干扰核心**的原因
  （见 [[digital-rf-memory|DRFM 页]]）。
