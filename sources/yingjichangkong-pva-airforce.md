# 《鹰击长空：志愿军空军在战斗中成长》

记述中国人民志愿军空军（及与朝鲜人民军空军的“中朝人民空军联合司令部”协作）自
1950 组建参战到 1953-07 停战的成长历程与空战故事。采用纪实化叙事（重个人英雄与战例），
含大量我方口径数字与人物事迹，并夹叙苏联空军幕后协作及所涉机型（米格-15、F-86、F-84、
波-2 等）。属**志愿军/解放军官方纪念叙事**文本，单侧视角明显，数字为我方统计口径。

## 结构与章节（按书内目录）

集中使用、择时作战”），空四师进浪头
二、首战告捷——28 大队实战锻练、李汉首破（1951-01-21）、9-25 大规模空战、11-06 人民
空军首次轰炸大和岛、11-30 第二次大和岛（F-86 突袭 Tu-2 编队）、螺旋桨击落喷气、水原夜袭
三、空中搏杀——李汉再捷、张积慧击毙戴维斯（1952-02-10）、韩德彩击落费席尔（1953-04-07）、
王海领大队破“圆圈阵”、赵宝桐、刘玉堤单机四捷
四、最后一战——聂凤智接（刘）指挥反败为胜、1953 六月护桥与最后一次空战（07-19）、
07-27 停战及全军总统计
