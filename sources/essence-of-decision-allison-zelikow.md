# 《Essence of Decision》（Allison & Zelikow, 2nd ed., 1999）

政治学/国际关系**经典分析著作**。第一版（Graham Allison, 1971）提出以古巴导弹危机检验三种政府行为
解释模型，成为“官僚政治”“组织过程”研究范式之作；第二版由 Allison 与历史学家 Philip Zelikow
合修订，据 1990s 解密的**美方档案**（FRUS 相关卷）、苏方档案研究（Fursenko & Naftali《One Hell of a
Gamble》1997）、肯尼迪录音带（May & Zelikow《The Kennedy Tapes》1997）**重写史实并修正第一版多处
判断**。作者自述本书为“全部新证据的首次分析性综合”。

## 结构（三模型 × 三案例）

| 章 | 内容 |
|---|---|
| ch1 | **Model I：理性行动者（Rational Actor）**——国家如单一理性行为体；含古典现实主义/新现实主义/制度主义/自由主义/战略选择等变体 |
| ch2 | 古巴导弹危机·**第一切面**——苏为何部署（4 假说：古巴保卫/冷战术/导弹力量/柏林）·美为何选择封锁（6 备选方案）·苏为何撤除 |
| ch3 | **Model II：组织行为（Organizational Behavior）**——组织逻辑与效率、组织文化、交互复杂性（以 NASA 为例） |
| ch4 | 古巴导弹危机·**第二切面**——部署之组织细节、封锁之组织实施（组织情报/组织备选/组织执行）、撤除 |
| ch5 | **Model III：政府政治（Governmental Politics）**——分权机构、说服之力、依程序谈判、权力=对结果的影响、集团过程（含“agency 问题”、议题设定、**groupthink**、联合行动的复杂性） |
| ch6 | 古巴导弹危机·**第三切面**——发现之政治、选择之政治、苏撤除（**苏击落美 U-2 飞行员**／**总统与主席**／**“交易”：解土耳其问题**／**“交易”：解古巴问题**） |
| ch7 | 结论：解释之差异、不同答案或不同问题、去向 |

## 本书的核心论点（原书）

- 三命题：①分析者/决策者以**隐含概念模型**思考外交与军事政策，模型对思考内容有重大影响；②解释政府
  行为的主流“**理性行动者**”框架（把国家当作中心协调的、有目的的个体）**遮蔽**了“决策者实为庞大组织与
  政治行为者的集合”这一事实；③另两个框架（组织行为、政府政治）可提供更贴近实际的解释。
- 三模型互为**透镜**：各自放大/揭示不同侧面。本书示范“同一事件、不同答案”并非矛盾，而是**不同问题**
  的结果（ch7）。

## 史料价值（对本库）

- **分析框架**：本书提供解释决策的通用镜片 → 建
  [[concepts/three-models-government-behavior|三模型框架]] 概念页（跨战争/跨事件可用）。
- **史实修正与补充**：本书据新档案对危机的关键节点给出**与叙事史不同侧重**的记述，尤其：
  - 苏部署动机之四假说与“**导弹力量**”论（[[concepts/anadyr-deployment-motives|Anadyr 部署动机]]）；
  - 土耳其交易的**秘密双轨**（公开信 + RFK 口头保证）与“**Rashomon/Trollope**”之辨
    （[[cuban-missile-crisis-turkey-deal-secret-channel-1962-10-27]]）；
  - 苏撤除决策之 Presidium 内情（[[cuban-missile-crisis-resolution-1962-10-28]]）。
- 与叙事史 [[one-minute-to-midnight-dobbs|Dobbs]] 互补：**Dobbs 给分钟级事件链，Allison/Zelikow
  给解释框架与档案级修正**；两源在关键事实上互证（U-2 击落、双 U-2 事件、土耳其私下保证、卡斯特罗
  电报），并各有侧重。
